# 2026-09-05 投稿UX・プロフィール画像・認定店表示順の修正

## 対応内容

- 観劇ログ入力モーダルを下部ナビより前面に出し、小さい画面でも内部スクロールで投稿ボタンまで操作できるようにした。
- 作品詳細から投稿した後はモーダルを閉じ、同じ作品ページに完了表示を出すようにした。
- 「記録する」から投稿した後は、投稿した作品の詳細ページへ戻るようにした。
- プロフィール画像選択後に、円形プレビュー上で位置と拡大率を調整してから保存できるようにした。
- トップの観劇一覧を「観た → 観る」の順にし、「観た」を初期表示にした。
- 長い作品名でも「最高」評価バッジが縦につぶれないようにした。
- 認定店の表示順を本番データ更新用マイグレーションで「燗味処 → il Legame」に固定した。

## 変更ファイル

- `frontend/src/views/WorkDetailView.vue`
- `frontend/src/views/ViewingLogCreateView.vue`
- `frontend/src/views/ProfileEditView.vue`
- `frontend/src/views/HomeView.vue`

## 確認結果

- フロントエンドの本番ビルド成功。
- 393px幅で投稿モーダルのスクロールとボタン表示を目視確認。
- 投稿後に同じ作品ページへ戻り、完了表示が出ることを確認。
- プロフィール画像の選択、円形切り抜きプレビュー、拡大率UIを目視確認。
- 長い作品名でも「最高」バッジが一行のまま表示されることを確認。
- SQLiteの単体テストで、認定店APIが「燗味処 → il Legame」を返すことを確認。

## 本番反映時の注意

- バックエンドのデプロイ時に `shops.0009_set_recognized_shop_display_order` を適用する必要がある。
- `Procfile` の release process で `manage.py migrate --noinput` が実行されるため、正しいHerokuアカウントからデプロイすれば順番も同時に反映される。
- 現在のローカルHeroku CLIは旧SK東京アカウントでログインされており、本番アプリへの権限がない。旧アカウントは使用せず、合同会社クウ側の正しいアカウントで認証してからデプロイする。
